## 📌 Features & Architecture
- ⚡ **Architectural Design System**: Minimalist paper (`#E6E4DE`) and ink (`#0B0B08`) alternating sections with accent coral (`#F0552D`).
- 💎 **Interactive 3D Hero**: Pinned 300vh scroll container featuring a native Three.js 3D extruded "HP" monogram with live 000°–360° degree tracking and solid-to-wireframe transitions.
- 📐 **About & Blueprint**: Animated SVG blueprint guides with a scroll-driven diagonal slash reveal and Figma-style vector bounding boxes.
- 📁 **Selected Projects**: Huge typographic rows with cursor-following thumbnail previews and full-screen case-study modal overlays with keyboard navigation.
- 🏆 **Highlights & Recognition**: Auto-advancing quote carousel with progress bars, hackathon milestones, and verified certificate preview modals.
- ⏱️ **Live Clock**: Real-time IST clock for Gandhinagar, Gujarat, India (`UTC+05:30`).
- ✉️ **Contact Form**: Direct message dispatch via EmailJS integration.

---

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4
- **3D Graphics**: Three.js (Native WebGL)
- **Smooth Scroll**: Lenis
- **Animations**: Framer Motion 12
- **Typography**: Inter Tight + JetBrains Mono
- **Deployment**: Vercel
